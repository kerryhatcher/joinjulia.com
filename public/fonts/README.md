# Julia Playbook

Julia Playbook is a modified version of Norwester by Jamie Wilson, version 1.2. Rounded curve runs were replaced with straight chamfers; metrics and Unicode mappings are retained. The derivative is renamed to respect Norwester's Reserved Font Name. SIL Open Font License 1.1; full license preserved in `norwester-OFL.txt`.

Original copyright: Copyright (c) October 14, 2013 Jamie Wilson (jamiewilson.io), with Reserved Font Name Norwester.

The original font and reproducible modification script are in `assets/fonts/`. Run `node assets/fonts/build-playbook-font.mjs` after installing project development dependencies to rebuild `julia-playbook.otf`.

Author repository: https://github.com/jamiewilson/norwester
Source archive: https://raw.githubusercontent.com/jamiewilson/norwester/gh-pages/assets/norwester.zip
